# db-adm-tui v1.12.0

_Дата релиза: 2026-11-24_

_[English](release-notes-v1.12.0.md) | Русский_

Релиз подставляет стандартные учётные значения в форме нового профиля.

## Значения по умолчанию

- PostgreSQL: пустой пользователь становится `postgres`, пустая база — тоже
  `postgres`. Это стандартные имена bootstrap-базы и роли; `initdb` допускает
  другое имя роли, но дистрибутивы используют `postgres`.
- MySQL/MariaDB: пустой пользователь становится `root` — начальной
  административной учётной записью, создаваемой при установке.
- MongoDB: стандартного login-пользователя нет, поле остаётся обязательным.
  Пустой `auth.db` становится `admin`.

## Когда применяются значения

- При переключении `engine` пустые или автоматически заполненные поля
  user/database/auth заполняются значениями нового движка; введённое вручную
  значение не перезаписывается.
- `Enter` с пустым полем, для которого есть значение по умолчанию, подключается
  с этим значением, не записывая его предварительно в форму.
- После успешного подключения профиль в окне сохранения уже содержит
  подставленные значения. При ошибке подключения форма остаётся без изменений.

Схема сохранённого профиля не изменилась.
