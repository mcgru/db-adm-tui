# db-adm-tui v1.10.3

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.10.3.md) | Русский_

Релиз перестраивает справочник клавиш в README.

## Справочник клавиш

- Единая смешанная таблица разделена на общие клавиши и контекстные разделы:
  выбор профиля, импорт, workspace, дерево, Details, Data/Results, строка
  запроса, матрица доступа и формы.
- Клавиши с разным смыслом перечислены в каждом контексте отдельно, а не одной
  универсальной строкой.
- Комбинации `Ctrl` теперь используют строчные буквы (`Ctrl+x`, `Ctrl+r`,
  `Ctrl+down` и т.д.), чтобы их нельзя было принять за `Ctrl+Shift+...`.

Поведение приложения не изменилось.
