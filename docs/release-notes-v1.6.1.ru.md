# db-adm-tui v1.6.1

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.6.1.md) | Русский_

Патч-релиз переключения панелей матрицы.

- `Tab`/`Shift+Tab` и `1`/`2` теперь сохраняют выбранный principal при
  переключении между `Role × Principal` и `Principal/Role × Object`.
- Пользователь/роль из столбца membership становится соответствующей строкой
  privileges; обратное переключение возвращает к столбцу этого principal.
- Целевая панель старается удержать principal в той же позиции на экране.
- Если у пользователя MongoDB нет строки privileges (пользователи там не
  редактируются), используется выбранная строка роли.

Изменений профилей, state и формата данных нет.
