# db-adm-tui v1.4.1

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.4.1.md) | Русский_

Патч-релиз для редактора ячеек из `v1.4.0`.

- Название поля, тег режима (`[val]`/`[DEF]`/`[NULL]`) и подставленное значение
  ячейки теперь компактно расположены в одной строке.
- Режим и значение разделены вертикальной чертой, поэтому начало значения
  видно сразу.
- Точка вставки отображается сплошным блок-курсором; он мигает, пока открыт
  редактор, и остаётся видимым после каждого нажатия клавиши.

Изменений профилей, state и формата данных нет. Архивы `v1.4.0` остаются
валидными; для исправления редактора используйте `v1.4.1`.
