# db-adm-tui v1.5.2

_Release date: 2026-11-20_

_[English](release-notes-v1.5.2.md) | [Русский](release-notes-v1.5.2.ru.md)_

Patch release for the statement editor.

- The edit modal now uses a compact `SQL> ` or `MQL> ` prompt.
- The text cursor starts immediately after the prompt instead of after the
  padded `SQL`/`MQL` label.
- The completion popup anchor follows the new prompt width.

No profile, state, or data-format changes.
