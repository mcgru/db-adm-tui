# db-adm-tui v1.8.0

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.8.0.md) | Русский_

Релиз упрощает детали матрицы и расширяет редактирование доступов к базам
PostgreSQL.

## Детали матрицы

- `e` и `Enter` открывают модальное окно деталей.
- `e` или `Esc` закрывают его без применения.
- `Enter` по-прежнему применяет привилегии или переключает membership.
- Подсказки в футере и действиях обновлены.

## Привилегии PostgreSQL

- Столбцы баз теперь включают все базы, видимые в дереве, а не только текущую.
  `CONNECT`/`CREATE`/`TEMPORARY` можно редактировать для любой из них из одной
  сессии.
- Столбцы schema/table остаются в пределах текущей базы/схемы.
- Views и column-level привилегии больше не редактируются; доступны только
  база, схема и таблица (для MongoDB — коллекция).

Изменений схемы профилей и формата данных нет.
