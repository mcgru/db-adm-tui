# db-adm-tui v1.5.3

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.5.3.md) | Русский_

Патч-релиз формы пользователя MongoDB и редактора statement.

## Форма пользователя MongoDB

- Auth-база по умолчанию — `admin`, что покрывает обычный случай.
- На поле базы `Space` переключает `admin` и базы, загруженные в дереве.
- Произвольную базу можно ввести вручную для нестандартных случаев; поле
  остаётся редактируемым.

## Редактор statement

- `Tab` открывает автодополнение в редакторе `Ctrl+X Ctrl+E`.
- Второй `Tab` принимает выбранный вариант.
- Поведение query bar не изменилось: `Tab` там по-прежнему переключает фокус.

Изменений профилей, state и формата данных нет.
