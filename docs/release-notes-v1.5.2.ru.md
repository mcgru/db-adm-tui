# db-adm-tui v1.5.2

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.5.2.md) | Русский_

Патч-релиз редактора statement.

- Модальное окно редактирования теперь использует компактный prompt `SQL> `
  или `MQL> `.
- Курсор ввода начинается сразу после prompt, а не после выровненной метки
  `SQL`/`MQL`.
- Позиция popup completion следует новой ширине prompt.

Изменений профилей, state и формата данных нет.
