# db-adm-tui v1.6.0

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.6.0.md) | Русский_

Релиз добавляет безопасное редактирование и удаление профилей, а также
мгновенное отображение переключателей в матрице.

## Редактирование профиля

- Изменение полей подключения обновляет source-файл с прежним паролем, а не
  оставляет устаревшую запись.
- PostgreSQL/MySQL/MariaDB: старая строка `.pgpass`/`.mypass` комментируется,
  новый tuple вставляется ниже; остальные строки сохраняются.
- MongoDB: URI записывается в канонический файл
  `.mongo.<USER>-in-<DATABASE>` с `authSource`, привязанным к выбранной базе;
  старый source-файл сохраняется, старая строка URI комментируется.
- Изменение только label или TLS не перезаписывает source-файл.

## Удаление профиля

- `Del` или `-` в picker открывают подтверждение для выбранного профиля.
- Удаляется только запись профиля. Source-файл `.pgpass`, `.mypass` или
  `.mongo.*` никогда не изменяется и не удаляется при удалении профиля.

## Обратная связь в матрице

- Ячейки membership и privileges обновляются оптимистично при нажатии `Space`.
- Матрица сохраняет загруженные ячейки видимыми во время фонового обновления;
  при ошибке мутации восстанавливается предыдущее native-состояние.

Изменений схемы профилей и формата данных нет.
