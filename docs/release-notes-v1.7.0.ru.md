# db-adm-tui v1.7.0

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.7.0.md) | Русский_

Релиз исправляет сохранение хостов MongoDB replica set и добавляет поле списка
хостов при создании пользователя MongoDB.

## Профили MongoDB

- Редактирование профиля MongoDB больше не сворачивает replica-set URI до
  первого хоста при изменении базы, пользователя или label.
- Полный список `host1:port1,host2:port2` и несекретные URI-опции читаются из
  source selector и сохраняются.
- При намеренном изменении хоста записывается новый host target.

## Создание пользователя MongoDB

- В форме появилось поле `hosts` после auth-базы.
- Оно по умолчанию содержит полный список хостов текущего профиля.
- Значение — список `host:port` через запятую; host без порта использует 27017.
- Сгенерированный credential URI `.mongo.<USER>-in-<DATABASE>` сохраняет полный
  список хостов и опции `authSource`/`replicaSet` профиля.

Изменений схемы профилей и формата данных нет.
