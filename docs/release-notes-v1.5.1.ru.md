# db-adm-tui v1.5.1

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.5.1.md) | Русский_

Патч-релиз формы пользователя MongoDB.

- Порядок полей теперь **name → password → database** и совпадает с
  отображением.
- Поле database по умолчанию содержит текущую базу; его можно заменить на
  `admin` или другую базу.
- В форме поясняется, что это **auth-база**, где хранится пользователь
  MongoDB, а не выдача доступа к базе. Роли назначаются отдельно через
  `Ctrl+X Ctrl+R` → `1 Role × Principal`.

Изменений профилей, state и формата данных нет.
