# db-adm-tui v1.11.0

_Дата релиза: 2026-11-24_

_[English](release-notes-v1.11.0.md) | Русский_

Релиз приводит создание профиля к виду редактирования и добавляет управление
TLS при создании и импорте.

## Форма нового подключения

- `n` открывает форму с полями, как в окне редактирования: engine, label, host,
  port, database, user, MongoDB `auth.db` и PostgreSQL-переключатель `no TLS`.
- `Space` на поле `engine` переключает PostgreSQL, MySQL/MariaDB и MongoDB.
  Порт следует стандартному значению движка, пока его не изменили вручную.
- `Tab`/`Shift+Tab` и `Up`/`Down` переключают поля.
- Подходящий источник `.pgpass`, `.mypass` или `.mongo.*` по-прежнему находится
  автоматически; иначе форма показывает masked-поле одноразового пароля.
- Профили PostgreSQL могут включить `allow_no_tls` сразу при создании.

## Импорт

- В окне импорта добавлено `t` → `no TLS [ ]`/`[x]` для выбранных записей
  PostgreSQL.
- Импортируемые MySQL/MariaDB и MongoDB записи это не затрагивает.

## Навигация

- Переход `Up`/`Down` по полям проверен для форм создания подключения,
  редактирования профиля и создания пользователя.
- `Space` переключает engine и TLS-флаг.

Схема сохранённого профиля не изменилась.
