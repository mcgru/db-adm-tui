# db-adm-tui v1.4.2

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.4.2.md) | Русский_

Патч-релиз для создания пользователей MongoDB.

- В форме пользователя появилось редактируемое поле **database**.
- Оно по умолчанию содержит текущую базу; перед созданием его можно заменить
  на `admin` или любую другую базу.
- Credential-файл и опциональный профиль используют выбранную базу
  (`.mongo.<USER>-in-<DATABASE>`, `<USER>@<DATABASE>`).
- Форма напоминает, что роли назначаются после создания через
  `Ctrl+X Ctrl+R` → `1 Principal × Role`.

Формы PostgreSQL и MySQL/MariaDB не изменились.
