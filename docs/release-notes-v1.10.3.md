# db-adm-tui v1.10.3

_Release date: 2026-11-20_

_[English](release-notes-v1.10.3.md) | [Русский](release-notes-v1.10.3.ru.md)_

This release reorganizes the README keyboard reference.

## Keyboard reference

- The single mixed key table is split into global keys and context sections:
  profile picker, import, workspace, tree, details, Data/Results, query bar,
  access matrix, and forms.
- Keys with different meanings are listed in each context instead of one
  multi-purpose row.
- `Ctrl` combinations now use lower-case key letters (`Ctrl+x`, `Ctrl+r`,
  `Ctrl+down`, and so on) so they cannot be mistaken for `Ctrl+Shift+...`.

No application behavior changed.
