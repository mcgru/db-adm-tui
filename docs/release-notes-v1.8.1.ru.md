# db-adm-tui v1.8.1

_Дата релиза: 2026-11-20_

_[English](release-notes-v1.8.1.md) | Русский_

Патч-релиз матрицы привилегий PostgreSQL.

- Столбцы баз снова соответствуют **текущему выбору в дереве**, а не всем
  видимым базам.
- Для выбранной базы показываются ячейки `CONNECT`/`CREATE`/`TEMPORARY`; для
  выбранной таблицы — schema/table scope.
- Текущий scope подсвечивается как `scope <database> · <object>` в футере
  матрицы.
- Views и column-level привилегии по-прежнему не редактируются.

Изменений схемы профилей и формата данных нет.
