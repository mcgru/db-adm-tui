# db-adm-tui v1.11.1

_Дата релиза: 2026-11-24_

_[English](release-notes-v1.11.1.md) | Русский_

Патч убирает скачок высоты в редакторе профиля и делает TLS-чекбокс явным.

## Редактор профиля

- Строка-подсказка PostgreSQL TLS теперь зарезервирована сразу при открытии
  окна редактирования.
- Переход фокуса на TLS-переключатель больше не меняет высоту модального окна и
  не сдвигает его по вертикали.
- Подсказка видна сразу, а не только после перехода к полю.

## TLS-чекбокс

- PostgreSQL-переключатель теперь называется `TLS` и включён по умолчанию.
- Снимите его через `Space`, чтобы разрешить plaintext-fallback после
  неудачной TLS-попытки.
- Форма создания подключения и импорт используют то же обозначение
  `TLS [x]`/`[ ]`. В импорте `t` переключает его для выбранных записей
  PostgreSQL.

Схема профиля и поведение подключения не изменились.
