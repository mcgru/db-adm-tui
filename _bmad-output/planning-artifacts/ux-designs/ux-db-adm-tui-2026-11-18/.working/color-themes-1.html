db-adm-tui · UX discovery · 2026-11-18

One dark theme. Five registers.

db-adm-tui is a keyboard-first database admin for closed environments. Each study below keeps the same 18 semantic roles; what changes is temperature, contrast, and how loudly the interface asks for attention. Pick a register, not a palette of one-off colors.
